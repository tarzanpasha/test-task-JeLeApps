
## Задание

Собеседование
Добрый день. Прошу выполнить тестовое задание или если есть подобный функционал, продемонстрировать его
1. Развернуть ларавел проект , либо использовать свой проект
2. Написать в ТГ https://t.me/... о начале выполнения тестового задания. Текст: «{фио}, ,бекенд, начал выполнять»
3. Разработать метод апи «Регистрация нового юзера» api/registration с параметрами email, password, gender
4. Разработать апи метод api/profile для выдачи данных Пользователя
5. Предоставить документацию в виде Postman проекта
6. Представить скриншоты запросов из Postman

7. Отправить в телеграмм https://t.me/.... демонстрации работы тестового задания
   Время выполнения- не более 3 часов

## Запуск

php artisan serve
php artisan config:cache

достать коллекцию postman из папки docs
импортировать в postman
выполнить http://localhost:8000/api/registration
полученный токен прописать в постман для api
http://localhost:8000/api/profile

убедиться, что данные пользователя выводятся.
